GenReSTCustom (doc/rest_docs.go:61-130) builds a reStructuredText page for a cobra.Command in one linear pass over a bytes.Buffer, then writes the buffer to the caller's io.Writer. Its signature is `func GenReSTCustom(cmd *cobra.Command, w io.Writer, linkHandler func(string, string) string) error`; the plain GenReST wrapper (doc/rest_docs.go:56-59) just calls it with `defaultLinkHandler`.

Initialization:
- It first normalizes the command by calling `cmd.InitDefaultHelpCmd()` and `cmd.InitDefaultHelpFlag()`.
- It creates `buf := new(bytes.Buffer)` and derives the page identity: `name := cmd.CommandPath()` (the full command path), `short := cmd.Short`, `long := cmd.Long`, falling back to `long = short` when Long is empty.
- It computes the reST anchor `ref := strings.ReplaceAll(name, " ", "_")`.

Header/title section:
- Emits the reST label `.. _<ref>:` followed by the command path as the title, underlined with `strings.Repeat("-", len(name))`.
- Writes the short description, then a "Synopsis" section header underlined with `~~~~~~~~`, containing the long description.

Usage and examples sections:
- If `cmd.Runnable()` is true, it writes a literal block `::` containing two-space-indented `cmd.UseLine()`.
- If `len(cmd.Example) > 0`, it writes an "Examples" section (underlined with `~~~~~~~~`) as a literal block with the example text indented via `indentString(cmd.Example, "  ")`.

Options section:
- It delegates to `printOptionsReST(buf, cmd, name)`, returning the error immediately if that call fails. (The body of printOptionsReST is not included in the provided responses.)

SEE ALSO section and links:
- Guarded by `hasSeeAlso(cmd)`, it writes a "SEE ALSO" header underlined with `~~~~~~~~`.
- Parent link: if `cmd.HasParent()`, it takes `parent := cmd.Parent()`, computes `pname := parent.CommandPath()` and its underscore ref, and emits a bullet `* <link> \t - <parent.Short>` where the link text comes from `linkHandler(pname, ref)`. It then runs `cmd.VisitParents` to propagate `DisableAutoGenTag` down from any ancestor that sets it.
- Child links: it takes `children := cmd.Commands()`, sorts them with `sort.Sort(byName(children))`, and for each child skips those where `!child.IsAvailableCommand() || child.IsAdditionalHelpTopicCommand()`. For the rest it builds `cname := name + " " + child.Name()` (using Command.Name(), which per command.go:1495-1503 is the first word of the Use line), computes the underscore ref, and writes `* <linkHandler(cname, ref)> \t - <child.Short>`. A trailing blank line follows the list.

Final output:
- Unless `cmd.DisableAutoGenTag` is set, it appends the footer `*Auto generated by spf13/cobra on <date>*` with the date formatted as `time.Now().Format("2-Jan-2006")`.
- It finishes with `_, err := buf.WriteTo(w)` and returns that error, so the whole page is buffered in memory and flushed to the writer in a single call.
