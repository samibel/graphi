`(*Command).execute` returns `flag.ErrHelp` before running the command in two cases:

- **The boolean `help` flag is true** (`command.go:895–905`), even if other flags are set.
- **The command isn’t runnable** (`command.go:923–925`): both `Run` and `RunE` are nil, per `Runnable()` (`command.go:1550–1553`).

Flag parsing happens first; a parsing error returns through `FlagErrorFunc()` before either check (`command.go:888–891`). Version handling occurs before the runnable check and can return early (`command.go:908–921`).
