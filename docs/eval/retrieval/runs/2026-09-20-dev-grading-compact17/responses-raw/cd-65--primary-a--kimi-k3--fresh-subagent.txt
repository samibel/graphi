func (c *Command) AllChildCommandsHaveGroup() bool {
	for _, sub := range c.commands {
		if (sub.IsAvailableCommand() || sub == c.helpCommand) && sub.GroupID == "" {
			return false
		}
	}
	return true
}

Behavior: it iterates over the receiver's c.commands slice and returns false as soon as it finds a subcommand that (a) is an available command (per IsAvailableCommand) or is the command's own helpCommand, and (b) has an empty GroupID. Otherwise it returns true. In other words, every available child command (plus the help command) must have a non-empty GroupID for the method to return true; deprecated/hidden commands and non-help commands that are neither runnable nor have available subcommands are excluded from the check because IsAvailableCommand filters them out.
