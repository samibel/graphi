For one command page, `GenMarkdownCustom` processes content in this order:

1. Initializes Cobra’s default help command and help flag (`doc/md_docs.go:58-59`).
2. Creates a buffer and obtains the full command path with `cmd.CommandPath()` (`doc/md_docs.go:61-62`).
3. Writes:

   - `## <command path>`
   - the command’s `Short` description (`doc/md_docs.go:64-65`)
   - `### Synopsis` plus `Long`, only when `Long` is nonempty (`doc/md_docs.go:66-69`)
   - a fenced code block containing `cmd.UseLine()`, only when the command is runnable (`doc/md_docs.go:71-73`)
   - `### Examples` plus a fenced `Example`, only when present (`doc/md_docs.go:75-78`)
   - options through `printOptions(buf, cmd, name)`, returning immediately on error (`doc/md_docs.go:80-82`)

4. If `hasSeeAlso(cmd)` is true, writes `### SEE ALSO` (`doc/md_docs.go:83-84`):

   - For a parent, it forms `<parent command path>.md`, replaces spaces with underscores, passes that filename through `linkHandler`, and emits a link with the parent’s short description (`doc/md_docs.go:85-90`).
   - It visits ancestors and propagates any `DisableAutoGenTag` setting to the current command (`doc/md_docs.go:91-95`).
   - It retrieves and name-sorts children (`doc/md_docs.go:98-99`; `command.go:1291-1300` also says `Commands()` returns sorted children when sorting is enabled).
   - It skips unavailable commands and additional help topics. For each remaining child, it forms `<current command path> <child name>.md`, replaces spaces with underscores, applies `linkHandler`, and emits the child link and short description (`doc/md_docs.go:101-109`).

5. Unless `DisableAutoGenTag` is set, appends a dated “Auto generated by spf13/cobra” footer (`doc/md_docs.go:112-114`).
6. Writes the completed buffer to the supplied writer and returns that write error (`doc/md_docs.go:115-116`).
