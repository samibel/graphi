Set `CompletionOptions.DisableDescriptions = true` on the root command to hide (completely disable) descriptions in shell completions.

Evidence: site/content/completions/_index.md:111-123 (ref_id e31) states: "To tell Cobra to completely disable descriptions for completions:\n```\nrootCmd.CompletionOptions.DisableDescriptions = true\n```". This is backed by the `CompletionOptions` struct in completions.go:105-111 (ref_id e32), which documents the field: "DisableDescriptions turns off all completion descriptions for shells".

Related: completions.go:94-106 (ref_id e30) also defines a `--no-descriptions` flag (`compCmdNoDescFlagName = "no-descriptions"`, `compCmdNoDescFlagDesc = "disable completion descriptions"`) that lets an end user pass `--no-descriptions` at completion-generation time to suppress descriptions per-invocation, and `DisableNoDescFlag` on `CompletionOptions` controls whether that flag is even offered. So there are two related mechanisms: `CompletionOptions.DisableDescriptions = true` (hard-disables descriptions everywhere, set by the program) versus the `--no-descriptions` flag (a per-invocation opt-out for shells that support descriptions, e.g. site/content/completions/_index.md:446-458, ref_id e29, shows `$ helm s[tab][tab]` "Without descriptions").
