`SetIn` replaces standard input (`stdin`) with the supplied `io.Reader`: it assigns `c.inReader = newIn` (`command.go:299–304`), whose field comment says it “replaces stdin” (`command.go:192–193`).

If the reader is nil, input is inherited from a parent if available; otherwise it falls back to `os.Stdin` (`getIn`, `command.go:413–422`; `InOrStdin`, `command.go:388–392`).
