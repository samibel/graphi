Persistent flags are declared in a command's separate `PersistentFlags()` set (`command.go:1725-1735`). Before a child uses its effective flags, `mergePersistentFlags` refreshes `parentsPflags`, then adds both the child's persistent set and the accumulated parent set to `c.Flags()` (`command.go:1847-1857`). Lookup likewise checks the current command's persistent flags and then refreshes and searches `parentsPflags` (`command.go:1805-1816`). Thus parent persistent flags become part of each descendant's effective flag set, while remaining distinguishable as inherited flags.
