`GenReSTCustom` builds the page in a buffer, then writes it to the supplied `io.Writer`:

1. **Initialize:** Calls `cmd.InitDefaultHelpCmd()` and `cmd.InitDefaultHelpFlag()`, creates a `bytes.Buffer`, and gets the full command name from `cmd.CommandPath()`. It uses `cmd.Long` for the description, falling back to `cmd.Short` when empty. (`doc/rest_docs.go:62–73`)

2. **Write the heading and synopsis:** Replaces spaces in the command path with underscores to form the reference anchor (`.. _<ref>:`). Writes the command path as a title with a hyphen underline, the short description, and a `Synopsis` section with the long description. If `cmd.Runnable()`, adds `cmd.UseLine()` as a two-space-indented literal block introduced by `::`. (`doc/rest_docs.go:74–86`)

3. **Add examples and options:** When `cmd.Example` is nonempty, writes an `Examples` section and a literal block using `indentString(cmd.Example, "  ")`. Calls `printOptionsReST(buf, cmd, name)` and immediately returns any error. The supplied snippets do not show that helper’s internals. (`doc/rest_docs.go:88–96`)

4. **Build related-command links:** If `hasSeeAlso(cmd)` is true, writes `SEE ALSO`. The parent, when present, comes first. Children are sorted with `byName`; unavailable commands and additional help-topic commands are skipped. Each bullet contains `linkHandler(commandPath, underscoreReference)` followed by that command’s short description. Child paths are constructed as `name + " " + child.Name()`. (`doc/rest_docs.go:97–124`)

5. **Finish and output:** Within the parent-link branch, `VisitParents` propagates any ancestor’s enabled `DisableAutoGenTag` to the command. Unless that flag is set, appends an autogenerated footer dated with `time.Now().Format("2-Jan-2006")`. Finally, calls `buf.WriteTo(w)` and returns its error. (`doc/rest_docs.go:105–109, 125–129`)
