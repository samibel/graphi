To find out what flags are being invoked/looked up for a cobra Command, the response points to a small cluster of functions/methods in command.go and completions.go:

1. cmd.Flags() — command.go:1643 (snippet e157, lines 1637-1649). This is the entry point: "Flags returns the complete FlagSet that applies to this command (local and persistent declared here and by all parents)." It lazily builds c.flags via flag.NewFlagSet(c.Name(), flag.ContinueOnError) if not already set. This is the FlagSet you query to see what flags exist/are registered for the command.

2. cmd.Flag(name) — command.go:1795 (snippet e159, lines 1789-1801), doc comment "Flag climbs up the command tree looking for matching flag." Implementation: `flag = c.Flags().Lookup(name)`, and if that's nil it falls back to `c.persistentFlag(name)` (command.go:1806, ref 6291636 cb0d0080b34b32c7). So to check whether a specific flag was declared/called on a command (including inherited from parents), you call cmd.Flag("name") rather than walking FlagSets yourself.

3. findFlag(cmd, name) — completions.go:841 (snippet e158, lines 835-847), a package-level helper used by completion code: `flagSet := cmd.Flags(); if len(name) == 1 { if short := flagSet.ShorthandLookup(name); short != nil { name = short.Name ... } }`. This shows how a short flag ("-f") is resolved to its long name before lookup, again by first calling cmd.Flags().

Related FlagSet accessors, all built on top of Flags()/LocalFlags(): LocalFlags() (command.go:1669), NonInheritedFlags() (command.go:1721, snippet e156 — literally `return c.LocalFlags()`), InheritedFlags() (command.go:1696), PersistentFlags() (command.go following NonInheritedFlags in the same snippet), and HasAvailableFlags()/HasAvailableInheritedFlags() (command.go:1773/1789) to check if any flags are present before iterating.

If instead you mean "which flags were passed as CLI args to invoke the command" (i.e., parsing os.Args rather than declared FlagSets), the relevant piece is stripFlags(args, c) (command.go:643, related item c3e28273a96f88e5) and its caller cmd.Find(args) (command.go:726, snippet e160, lines 720-732): `argsWOflags := stripFlags(innerArgs, c)`. Command.Find walks the command tree using stripFlags to separate flag tokens from positional args so it can locate the target subcommand; stripFlags is what recognizes an arg as a flag (looking at the "--" / "-" prefix logic shown just above it in command.go around line 719-722 in the same snippet region).

In short: call cmd.Flags() to get the FlagSet of a command, then either iterate it or use cmd.Flag(name)/findFlag(cmd, name) to look up a specific flag by name (long or short); use stripFlags/cmd.Find to see how cobra itself distinguishes flag tokens from command/arg tokens when parsing the invocation.
