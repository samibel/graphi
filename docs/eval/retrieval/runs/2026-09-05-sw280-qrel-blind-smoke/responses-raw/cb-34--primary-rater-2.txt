// Usage puts out the usage for the command.
// Used when a user provides invalid input.
// Can be defined by user by overriding UsageFunc.
func (c *Command) Usage() error {
	return c.UsageFunc()(c)
}

So Usage() prints the usage message for a command, and is triggered when a user supplies invalid input. It delegates to c.UsageFunc()(c) rather than doing formatting itself.

// or a parent, or it returns a default usage function.

This shows usage behavior is overridable per-command (via c.usageFunc) and falls back through the parent command chain (c.HasParent() / c.Parent().UsageFunc()), otherwise using a built-in default.

The function can be set explicitly via SetUsageFunc (command.go:307, evidence e33, snippet 301-313):
// SetUsageFunc sets usage function. Usage can be defined by application.
func (c *Command) SetUsageFunc(f func(*Command) error) {
	c.usageFunc = f
}
