To test whether a command has inherited flags, call `cmd.HasInheritedFlags()`: it returns `c.InheritedFlags().HasFlags()` (`command.go:1766–1769`). To restrict the check to inherited flags that are neither hidden nor deprecated, use `cmd.HasAvailableInheritedFlags()` (`command.go:1788–1792`). The `InheritedFlags()` implementation begins by merging persistent flags (`command.go:1696–1697`).
