`(*Command).Flags() *flag.FlagSet` returns the complete flag set applying to a command, documented as local and persistent flags declared there and by its parents (`command.go:1641–1643`). If `c.flags` is nil, it creates a set named `c.Name()` with `flag.ContinueOnError` (`command.go:1644–1645`). Related accessors are `LocalFlags()` for flags set on the current command (`command.go:1668–1670`) and `InheritedFlags()` for parent flags (`command.go:1695–1697`).
