`(*Command).Execute()` runs the command tree using the configured arguments—`os.Args[1:]` by default—by calling `c.ExecuteC()`. It discards the returned `*Command` and returns only the error (`command.go:1035–1041`, symbols `Execute` and `ExecuteC`).

`ExecuteC()` initializes a missing context with `context.Background()` and delegates execution to the root command when invoked on a child (`command.go:1051–1062`).
