You cannot read parsed persistent-flag values in Go’s package `init()` because parsing occurs later during command execution (`command.go:883–898`).

Register a callback with `OnInitialize(...)` instead (`cobra.go:97–101`). It runs via `preRun()` after `ParseFlags(a)` (`command.go:926`, `command.go:1015–1019`). Inside that callback, access the command’s flag with `cmd.Flag("name")`; `Command.Flag` searches both local and persistent flags (`command.go:1794–1803`).
