Implement custom completion in Go with a command's `ValidArgsFunction` and/or `RegisterFlagCompletionFunc`, rather than a Bash-script annotation. Those Go mechanisms are portable across Bash, Zsh, Fish, and PowerShell (`site/content/completions/_index.md:477-478`). Cobra's generated shell scripts invoke the hidden `__complete` command (or `__completeNoDesc`) to request results from the program (`completions.go:25-34`); for Zsh, `GenZshCompletion` emits the script to an `io.Writer` (`zsh_completions.go:29-33`).
