`shell_completions.go` provides flag helpers affecting shell completion. `(*Command).MarkFlagFilename` limits completion to supplied file extensions through `MarkFlagFilename(c.Flags(), name, extensions...)` (`shell_completions.go:42–46`); `MarkPersistentFlagFilename` does the same through `c.PersistentFlags()` (`shell_completions.go:58–63`). `MarkFlagRequired` prioritizes the named flag during completion and causes an error when the command is invoked without it (`shell_completions.go:35–38`).
