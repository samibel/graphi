`doc/man_docs.go` provides man-page generation: `GenMan(cmd *cobra.Command, header *GenManHeader, w io.Writer) error` writes a command's man page and allows a nil header (`doc/man_docs.go:103–106`); `GenManTreeOptions` includes `Header` and `Path` (`82–86`). `fillHeader` defaults the title to the uppercase command name with spaces escaped as `\-`, the section to `1`, and the date to the current time or parsed `SOURCE_DATE_EPOCH`. It formats the date as `Jan 2006`, rejects an invalid epoch, and supplies the auto-generation source when enabled (`118–141`).
