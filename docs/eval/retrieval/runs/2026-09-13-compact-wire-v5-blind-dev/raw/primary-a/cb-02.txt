`(*Command).MarkFlagsMutuallyExclusive(names...)` first merges inherited persistent flags, then requires every named flag to exist. For each flag it appends the space-joined set of names to the `cobra_annotation_mutually_exclusive` annotation; a missing flag or annotation error causes a panic. Repeated calls create separate group entries, so a flag may belong to multiple groups (`flag_groups.go:25-29`, `flag_groups.go:63-78`).
