doc/man_docs.go contains man-page generation and header support: GenMan writes a command's man page to an io.Writer and permits a nil header (lines 103-106), while GenManTreeOptions holds tree-generation options (lines 82-86). fillHeader supplies an uppercase escaped title, default section "1", and a date from SOURCE_DATE_EPOCH or the current time, rejecting an invalid epoch. It formats the date as "Jan 2006" and supplies an autogenerated source unless disabled (lines 118-141).
