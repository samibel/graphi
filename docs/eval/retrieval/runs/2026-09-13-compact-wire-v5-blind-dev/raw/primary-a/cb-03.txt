`GenMarkdownTree(cmd, dir)` generates Markdown for the command and all descendants by delegating to `GenMarkdownTreeCustom` with an empty file prepender and identity link handler (`doc/md_docs.go:119-130`). The custom function recursively visits available, non-help-topic children, then writes the current command to `<CommandPath with spaces replaced by underscores>.md` under `dir` and calls `GenMarkdownCustom` (`doc/md_docs.go:131-158`). Command-name collisions involving `-` are explicitly documented as undefined (`doc/md_docs.go:119-125`).
