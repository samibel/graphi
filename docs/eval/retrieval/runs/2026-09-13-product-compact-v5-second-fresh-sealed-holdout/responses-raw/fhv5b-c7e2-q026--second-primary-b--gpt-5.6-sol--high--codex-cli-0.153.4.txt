Usage rendering looks first at the command’s `usageFunc`; if absent, it recursively checks the parent via `c.Parent().UsageFunc()` ([command.go:424–433](command.go)). The built-in fallback calls `c.mergePersistentFlags()`, then renders `c.UsageTemplate()` with the command as template data to `c.OutOrStderr()` using `tmpl`; rendering errors are printed with `c.PrintErrln(err)` and returned ([command.go:434–440](command.go)). `Usage()` invokes the selected function as `c.UsageFunc()(c)` ([command.go:443–448](command.go)).
