`GenMarkdownTree(cmd *cobra.Command, dir string) error` generates a Markdown page for the command and all descendants in the supplied directory (`doc/md_docs.go:119–126`). Its comment warns that hyphens in command names can cause ambiguous output filenames. `GenMarkdownTreeCustom` is the variant accepting custom `filePrepender` and `linkHandler` functions (`doc/md_docs.go:131–134`). The related page generator, `GenMarkdownCustom`, writes the command path, short description, optional synopsis, runnable usage, examples, options, and SEE ALSO links (`doc/md_docs.go:56–97`); the full tree-generation body is not included.
