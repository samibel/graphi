The man-page tree generator performs a depth-first, children-first walk over `cmd.Commands()`. It skips unavailable commands and additional help-topic commands, recursively generates each eligible child, and then writes the current command's page (`doc/man_docs.go:46-80`). The filename is derived from `CommandPath`, using the configured separator (default `_`) and section (default `1`), under the configured output path (`doc/man_docs.go:61-80`).
