Check that the command's `Version` field is nonempty, for example `cmd.Version = "1.0.0"`. The automatic `--version` flag is added only when `Version` is nonempty and no `version` flag is already defined; when specified, it prints `Version` (`command.go:108–110`). `InitDefaultVersionFlag` explicitly does nothing if a version flag exists or `c.Version` is empty (`command.go:1202–1206`). The bundle does not show your command configuration, so it cannot identify which condition applies to your case.
