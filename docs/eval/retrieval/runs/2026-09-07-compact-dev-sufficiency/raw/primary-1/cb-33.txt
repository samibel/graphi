`(*Command).Flags() *flag.FlagSet` is documented as returning the complete flag set applying to the command, including local and persistent flags declared there and by parents (`command.go:1641–1643`). If `c.flags` is nil, it creates a set named `c.Name()` with `flag.ContinueOnError` (`command.go:1644–1645`). Related methods are `LocalFlags()` for flags set on the current command (`command.go:1668–1670`), `InheritedFlags()` for parent flags (`command.go:1695–1697`), and `ResetFlags()` to delete all command flags (`command.go:1737–1740`).
