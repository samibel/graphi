`(*Command).MarkFlagsMutuallyExclusive(flagNames ...string)` annotates a set of flags so invoking the command with more than one of them is an error (`flag_groups.go:63–65`). It merges persistent flags, looks up every named flag, panics if one is missing, and appends the space-joined group names to each flag's `mutuallyExclusive` annotation. Appending allows a flag to belong to multiple groups; annotation errors also panic (`flag_groups.go:66–78`). `ValidateFlagGroups` is the related validation entry point and skips validation when flag parsing is disabled (`flag_groups.go:80–85`).
