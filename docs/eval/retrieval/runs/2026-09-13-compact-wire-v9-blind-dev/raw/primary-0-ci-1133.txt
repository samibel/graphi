Inside the executing command’s `Run`, `RunE`, or pre-run hook, use the provided `cmd` and call:

```go
f := cmd.Flag("flag-name")
if f != nil {
    // use f.Value, f.Changed, etc.
}
```

`Command.Flag(name)` first checks the command’s local flags with `c.Flags().Lookup(name)`, then searches inherited persistent flags via `c.persistentFlag(name)` ([command.go, lines 1794–1803]). The currently executing command is passed as `cmd *Command` to hooks such as `Run`, `RunE`, `PreRun`, and `PreRunE` ([command.go, lines 124–134]).
