Persistent flags are stored separately on each command by `PersistentFlags` (`command.go:1725-1735`). Before a command needs its complete flags, `mergePersistentFlags` calls `updateParentsPflags`, then adds both its own persistent set and the accumulated parent-persistent set to `c.Flags()` (`command.go:1847-1857`). A named persistent lookup checks the current command first, then refreshes and searches `parentsPflags` (`command.go:1805-1816`).
