`(*Command).RegisterFlagCompletionFunc` registers a Go callback for completion of a named flag; the callback receives the command, arguments, and current text and returns completion strings plus a `ShellCompDirective` (`completions.go:132–133`). It rejects a nonexistent flag and duplicate registration, locks `flagCompletionMutex`, stores the callback in `flagCompletionFunctions` keyed by the flag, and returns nil on success (`completions.go:134–147`). `GetFlagCompletionFunc` retrieves it under a read lock and returns the callback plus an existence boolean (`completions.go:149–161`). The recommendation in `shell_completions.go:52–53` says these Go completion functions work across all shells.
