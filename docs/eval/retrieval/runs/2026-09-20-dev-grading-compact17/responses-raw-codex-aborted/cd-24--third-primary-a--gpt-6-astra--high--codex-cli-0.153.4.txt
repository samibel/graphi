`(*Command).execute` explicitly returns `flag.ErrHelp` instead of running the command when:

- The boolean `help` flag is true, after successful flag parsing (`command.go:888–905`).
- The command is not runnable (`command.go:923–925`): both `Run` and `RunE` are nil, per `Runnable()` (`command.go:1549–1553`). This check comes after version handling, so a defined version with the `version` flag set returns from that handling first.

Both checks occur before execution hooks, argument validation, and `Run`/`RunE`. Flag-parsing errors return through `FlagErrorFunc()` before either check (`command.go:888–891`).
