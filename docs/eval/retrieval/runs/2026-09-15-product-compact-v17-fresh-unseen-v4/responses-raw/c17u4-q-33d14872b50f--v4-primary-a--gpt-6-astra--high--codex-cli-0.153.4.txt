Call `SetHelpFunc` on the command with a function of type `func(*Command, []string)`:

```go
cmd.SetHelpFunc(func(c *cobra.Command, args []string) {
    // Write your application's help output.
})
```

`SetHelpFunc` stores the callback in `c.helpFunc` (`command.go:321–325`). `HelpFunc()` uses that callback, otherwise inherits the parent’s function, otherwise uses the default (`command.go:449–468`). Thus, setting it on the root command also applies to children unless they override it, as documented in `site/content/user_guide.md:541–553`.
