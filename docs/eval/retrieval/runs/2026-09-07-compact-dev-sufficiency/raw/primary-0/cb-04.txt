`(*Command).RegisterFlagCompletionFunc(flagName string, f func(cmd *Command, args []string, toComplete string) ([]string, ShellCompDirective)) error` registers a completion function for a flag and begins by resolving it with `c.Flag(flagName)` (`completions.go:132–134`). The callback returns completion strings and a `ShellCompDirective`. This Go completion mechanism works across all shells (`shell_completions.go:51–53`). `GetFlagCompletionFunc(flagName)` retrieves a registered callback with an availability boolean (`completions.go:148–150`).
