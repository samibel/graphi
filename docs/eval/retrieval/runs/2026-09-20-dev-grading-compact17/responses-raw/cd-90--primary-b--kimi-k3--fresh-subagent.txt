Set the `DisableSuggestions` field on your command to `true`:

```go
command.DisableSuggestions = true
```

Evidence:

- `site/content/user_guide.md` lines 694-734 (section "Suggestions when \"unknown command\" happens") states: "If you need to disable suggestions or tweak the string distance in your command, use: `command.DisableSuggestions = true` or `command.SuggestionsMinimumDistance = 1`."
- `command.go` line 248 declares the field with the comment "// DisableSuggestions disables the suggestions based on Levenshtein distance".
- `command.go` lines 749-765 show the behavior in `func (c *Command) findSuggestions(arg string) string`: the first thing it does is `if c.DisableSuggestions { return "" }`, so no "Did you mean this?" block is produced when the flag is set. That function's result is what gets appended to the "invalid argument" error in `args.go` line 61 (`cmd.findSuggestions(args[0])`).

Related knobs mentioned in the same source: raising/lowering the match threshold via `command.SuggestionsMinimumDistance` (defaulted to 2 in `findSuggestions` when `<= 0`), and the `SuggestFor` attribute for explicit suggestion aliases — but `DisableSuggestions = true` is the direct way to turn the automatic suggestions off.
