On the currently executing `*Command`, use `cmd.Flag("flag-name")` to obtain the flag object. `Flag(name string)` returns `*flag.Flag`, first looks up the name in `c.Flags()`, and is documented to climb the command tree for a match (`command.go:1794–1796`). If you specifically want the lookup in that command's flag set, the shown expression is `cmd.Flags().Lookup("flag-name")` (`command.go:1796`).
