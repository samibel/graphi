`(*Command).Flags() *flag.FlagSet` returns the command's flag set, documented to cover local and persistent flags declared on the command and its parents (`command.go:1641–1643`). It lazily initializes `c.flags` with `flag.NewFlagSet(c.Name(), flag.ContinueOnError)`, creates an error buffer if needed, sets that buffer as output, and returns the cached set (`command.go:1644–1653`). The body itself does not merge parent flags; the related `InheritedFlags()` explicitly calls `mergePersistentFlags()` before building its inherited set (`command.go:1695–1703`). `LocalNonPersistentFlags` is the accessor for flags that do not persist to subcommands (`command.go:1655–1660`).
