From the child command, call `cmd.Flag("name")`. It checks the child's applicable flag set, then `persistentFlag` checks local persistent flags and refreshes/searches the accumulated parent persistent flags (`command.go:1794-1816`). `updateParentsPflags` builds that set by visiting every parent and adding each parent's `PersistentFlags()` (`command.go:1855-1874`). The returned `*pflag.Flag` contains the flag's current value.
