`flag_groups.go` implements flag-group processing and validation. `ValidateFlagGroups` skips work when `DisableFlagParsing` is true, then visits flags to build status maps for `requiredAsGroup`, `oneRequired`, and `mutuallyExclusive` annotations (`flag_groups.go:81–99`). `processFlagForGroupAnnotation` splits each annotated group into flag names and only considers groups whose flags are all defined, checked by `hasAllFlags` (`flag_groups.go:111–134`). `validateRequiredFlagGroups` permits either none or all of a group's flags to be set; otherwise it sorts the missing names and returns an error identifying the group and missing flags (`flag_groups.go:144–165`).
