For a flag, call `cmd.RegisterFlagCompletionFunc("flag", func(cmd *cobra.Command, args []string, toComplete string) ([]string, cobra.ShellCompDirective) { ... })`; the required callback signature is shown in `completions.go:133-134`. Cobra stores these functions per flag (`completions.go:36`). For argument completion, use `ValidArgsFunction`; both it and `RegisterFlagCompletionFunc` are portable across bash, zsh, fish, and PowerShell (`site/content/completions/_index.md:477-478`).
