`GetActiveHelpConfig` first reads the global `COBRA_ACTIVE_HELP` setting. If its value is exactly `"0"`, it returns `"0"` and ignores the program-specific setting. Otherwise, it reads and returns `<PROGRAM>_ACTIVE_HELP`, derived from the root command’s name via `activeHelpEnvVar(cmd.Root().Name())`.

Evidence: `active_help.go:51-57`; constants `activeHelpGlobalEnvVar = "COBRA_ACTIVE_HELP"` and `activeHelpGlobalDisable = "0"` at `active_help.go:24-31`.
