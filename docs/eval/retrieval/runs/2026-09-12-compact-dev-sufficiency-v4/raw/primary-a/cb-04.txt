`(*Command).RegisterFlagCompletionFunc(flagName string, f func(cmd *Command, args []string, toComplete string) ([]string, ShellCompDirective)) error` registers a flag completion callback (`completions.go:132–146`). It resolves `c.Flag(flagName)`, returns an error if absent, locks `flagCompletionMutex`, rejects duplicate registrations, and stores `f` in `flagCompletionFunctions[flag]`. `GetFlagCompletionFunc` retrieves the function and an existence boolean under a read lock (`completions.go:148–161`). The comment in `shell_completions.go:52–53` recommends this Go callback mechanism for use across shells.
