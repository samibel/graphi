`doc/man_docs.go` implements man-page generation. `GenMan(cmd *cobra.Command, header *GenManHeader, w io.Writer) error` writes a command's man page to `w`; it accepts a nil header and initializes an empty `GenManHeader`, while `w` must not be nil (`doc/man_docs.go:103–108`). `fillHeader` defaults an empty title to the uppercase command name with spaces replaced by escaped hyphens, and an empty section to `"1"` (`doc/man_docs.go:118–124`). `GenManTreeOptions`, used by `GenManTreeFromOpts`, includes `Header` and `Path` fields (`doc/man_docs.go:82–86`).
