In `doc/man_docs.go`, `fillHeader` fills missing values as follows:

- **Title:** Replaces spaces in `name` with literal `\-`, then uppercases it using `strings.ToUpper(strings.ReplaceAll(...))` (lines 119–121). The caller supplies `cmd.CommandPath()` as `name` (line 109).
- **Section:** Defaults to `"1"` (lines 122–124).
- **Date:** If nil, defaults to `time.Now()`. A nonempty `SOURCE_DATE_EPOCH` overrides it, parsed as a base-10, 64-bit integer and converted with `time.Unix(unixEpoch, 0)`. Invalid input returns an `invalid SOURCE_DATE_EPOCH` error (lines 125–135). The resulting or supplied date is formatted as `"Jan 2006"` into `header.date` (line 136).
- **Source:** Defaults to `"Auto generated by spf13/cobra"` only when empty and `disableAutoGen` is false (lines 137–139).
