`helpOrVersionFlagPresent(cmd)` returns `true` if **either** the `"version"` or `"help"` flag in `cmd.Flags()` satisfies all three conditions:

- `Lookup` returns a non-`nil` flag.
- `len(flag.Annotations[FlagSetByCobraAnnotation]) > 0`.
- `flag.Changed` is `true`.

The `"version"` check occurs first (`completions.go:523–526`), followed by `"help"` (`completions.go:527–530`). If neither qualifies, it returns `false` (`completions.go:531`). It does not check the flag’s value.
