To write a custom help command, you can use `cmd.SetHelpCommand(cmd *Command)` to provide your own Help command (site/content/user_guide.md:541). Additionally, you can define custom help by overriding HelpFunc, as documented in the Help() method comment which states "Can be defined by user by overriding HelpFunc" (command.go:473). The cobra.Command type supports these customization approaches through the Help() method and SetHelpCommand() function to replace the default help behavior.
