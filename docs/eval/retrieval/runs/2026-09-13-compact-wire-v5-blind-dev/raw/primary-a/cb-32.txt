`(*Command).Execute()` runs command-line processing using explicit command args or `os.Args[1:]` by default, walking the command tree to match commands and flags. It delegates to `ExecuteC`, discards the returned command, and returns only the error (`command.go:1035-1042`). To supply a context, `ExecuteContext` stores it and then calls `Execute`; `ExecuteContextC` is the analogous command-returning form (`command.go:1027-1034`, `command.go:1043-1049`).
