`doc/man_docs.go` generates man pages. `GenMan` fills a default header, renders the command to man-page bytes, and writes them to the supplied writer (`doc/man_docs.go:103-116`). `fillHeader` supplies a normalized uppercase title, section `1`, a reproducible date from `SOURCE_DATE_EPOCH` when present, and an autogenerated source label unless disabled (`doc/man_docs.go:118-141`). Tree-generation options include `Header`, output `Path`, and `CommandSeparator` (`doc/man_docs.go:82-88`).
