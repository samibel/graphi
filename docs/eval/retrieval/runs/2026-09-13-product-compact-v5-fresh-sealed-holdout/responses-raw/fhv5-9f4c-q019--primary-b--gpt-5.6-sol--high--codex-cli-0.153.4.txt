In `doc/man_docs.go:118-141`, `fillHeader` supplies missing values as follows:

- `Title`: uppercases `name` after replacing spaces with `\-`:
  `strings.ToUpper(strings.ReplaceAll(name, " ", "\\-"))`
- `Section`: defaults to `"1"`.
- `Date`: defaults to `time.Now()`. If `SOURCE_DATE_EPOCH` is set, it parses it as a base-10 Unix timestamp and uses `time.Unix(unixEpoch, 0)`; invalid values return `invalid SOURCE_DATE_EPOCH`. It then formats the internal `header.date` as `"Jan 2006"`.
- `Source`: defaults to `"Auto generated by spf13/cobra"` only when `disableAutoGen` is false; otherwise it remains empty.
