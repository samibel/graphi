After defining the flags, call `cmd.MarkFlagsMutuallyExclusive("flag-a", "flag-b")`, using the flag names. `MarkFlagsMutuallyExclusive` merges persistent flags, looks up each name, and annotates each member with the space-joined group; it panics if a flag is missing (`flag_groups.go:65–77`). Flags can belong to multiple groups because annotations are appended. `ValidateFlagGroups` is documented to enforce these groups (`79–80`), and completion hides the other group members when one is present (`223–224`).
