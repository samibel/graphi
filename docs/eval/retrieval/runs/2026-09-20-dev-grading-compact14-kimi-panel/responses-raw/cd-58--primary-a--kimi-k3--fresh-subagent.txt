"Usage" in this codebase (the spf13/cobra project) shows up at two levels: end-user usage documentation in the README, and a usage-message API on the Command type in command.go.

1. README-level usage. The README's "# Usage" section (README.md:89-101) explains that `cobra-cli` is "a command line program to generate cobra applications and command files" that "will bootstrap your application scaffolding to rapidly develop a Cobra-based application", and calls it "the easiest way to incorporate Cobra into your application"; the span ends mid-sentence with "It can be installed by running:". The follow-up read (README.md:81-94) covers the preceding "# Installing" section: install the library with `go get -u github.com/spf13/cobra@latest`, then include it in your application with `import "github.com/spf13/cobra"`.

2. The Usage API on Command (command.go):
   - `func (c *Command) Usage() error` (command.go:443-448) "puts out the usage for the command", is "used when a user provides invalid input", and "can be defined by user by overriding UsageFunc"; its body is simply `return c.UsageFunc()(c)`.
   - `func (c *Command) UsageFunc() (f func(*Command) error)` (command.go:424-441) "returns either the function set by SetUsageFunc for this command or a parent, or it returns a default usage function." The resolution order is: `c.usageFunc` if non-nil, else `c.Parent().UsageFunc()` when `c.HasParent()`, else a default closure that calls `c.mergePersistentFlags()` and renders `tmpl(c.OutOrStderr(), c.UsageTemplate(), c)`, reporting any error via `c.PrintErrln(err)`.
   - `func (c *Command) UsageString() string` (command.go:478-495) "returns usage string": it stashes `c.outWriter`/`c.errWriter`, redirects both to a `bytes.Buffer`, calls `CheckErr(c.Usage())`, restores the original writers, and returns `bb.String()`.
   - The Command struct doc (command.go:49-57) ties "usage" to the `Use` field: "`Use` is the one-line usage message", with recommended syntax `[ ]` for an optional argument, `...` to indicate multiple values for the previous argument, and `|` for mutually exclusive alternatives.

In short: for a user of the library, "Usage" is about installing Cobra (`go get -u github.com/spf13/cobra@latest`) and optionally using cobra-cli scaffolding; for the API, "usage" is the per-command help/usage output produced by `Usage()` via the overridable `UsageFunc()` (inheritable from parents, defaulting to a rendered `UsageTemplate()`), and capturable as a string through `UsageString()`.
