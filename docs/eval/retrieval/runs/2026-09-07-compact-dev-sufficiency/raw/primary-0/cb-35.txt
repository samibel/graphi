Shell completion is documented in `site/content/completions/_index.md`. `InitDefaultCompletionCmd()` skips initialization when `CompletionOptions.DisableDefaultCmd` is true or the command has no subcommands; its comment also lists an existing program-provided `completion` command as a reason to skip (`completions.go:681–685`). Set `rootCmd.CompletionOptions.DisableDescriptions = true` to disable completion descriptions (`site/content/completions/_index.md:111–114`). Completion callbacks must avoid debug prints to stdout because scripts interpret them as completion choices (`site/content/completions/_index.md:270`).
