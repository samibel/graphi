Define the flags first, then pass their names to:

```go
cmd.MarkFlagsMutuallyExclusive("flag-a", "flag-b")
```

`MarkFlagsMutuallyExclusive(flagNames ...string)` annotates the flags so the command errors if more than one is supplied (`flag_groups.go:62-77`). Every named flag must already exist: it calls `c.Flags().Lookup(v)` and panics if a flag is missing (`flag_groups.go:67-71`). Each call creates one exclusive group, and a flag may belong to multiple groups (`flag_groups.go:72-73`).
