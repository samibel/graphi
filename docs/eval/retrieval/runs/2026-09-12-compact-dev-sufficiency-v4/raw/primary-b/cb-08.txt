`doc/man_docs.go` contains man-page generation support: `GenMan(cmd *cobra.Command, header *GenManHeader, w io.Writer) error` writes a command's man page, allowing a nil header but requiring a writer (`doc/man_docs.go:103–106`), and `GenManTreeOptions` contains at least `Header` and `Path` options for `GenManTreeFromOpts` (`doc/man_docs.go:82–86`). `fillHeader` defaults the title to an uppercase command name with spaces replaced by escaped hyphens, the section to `1`, and the date to the current time or parsed `SOURCE_DATE_EPOCH`; malformed epoch values return an error. It formats the date as `Jan 2006` and fills an empty source with `Auto generated by spf13/cobra` unless automatic generation attribution is disabled (`doc/man_docs.go:118–141`).
