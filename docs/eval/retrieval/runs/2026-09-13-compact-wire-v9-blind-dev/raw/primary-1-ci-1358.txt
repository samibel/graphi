`flag_groups.go:62-77` defines `(*Command).MarkFlagsMutuallyExclusive(flagNames ...string)` and states that the command errors if more than one flag in the set is used. Each name must already exist: `c.Flags().Lookup(v)` panics when a flag cannot be found (`flag_groups.go:67-71`). Calling the method multiple times creates separate groups, so a flag may belong to multiple groups (`flag_groups.go:72-75`).
