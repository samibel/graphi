VisitParents walks upward from the receiver command to the root by simple recursion on the parent pointer, invoking the callback once per ancestor.

The full implementation (command.go, lines 852-858):

    // VisitParents visits all parents of the command and invokes fn on each parent.
    func (c *Command) VisitParents(fn func(*Command)) {
        if c.HasParent() {
            fn(c.Parent())
            c.Parent().VisitParents(fn)
        }
    }
