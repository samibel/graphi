`RegisterFlagCompletionFunc` is a method on `*Command` that registers a shell-completion callback for a named flag:

```go
func (c *Command) RegisterFlagCompletionFunc(
    flagName string,
    f func(cmd *Command, args []string, toComplete string) ([]string, ShellCompDirective),
) error
```

It:

- Resolves the flag using `c.Flag(flagName)`.
- Returns an error if the flag does not exist.
- Uses `flagCompletionMutex` for synchronized access.
- Returns an error if that flag already has a registered callback.
- Otherwise stores the callback in `flagCompletionFunctions` and returns `nil`.
