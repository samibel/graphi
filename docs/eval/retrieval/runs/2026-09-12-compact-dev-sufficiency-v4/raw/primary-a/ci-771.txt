Use Go completion callbacks: `ValidArgsFunction` for command arguments and `RegisterFlagCompletionFunc()` for flags. The documentation explicitly says these callbacks are portable across `bash`, `zsh`, `fish`, and `powershell`, while legacy Bash-script custom completions and `BashCompCustom` are ignored by zsh (`site/content/completions/_index.md:477–478`). Generate the completion file for the desired supported shell; the supported set is listed in `site/content/user_guide.md:742–743`. For zsh, `GenZshCompletion(w)` writes the generated script with descriptions to a writer (`zsh_completions.go:29–33`, `80–85`).
