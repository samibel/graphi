flag_groups.go implements flag-group validation. ValidateFlagGroups skips validation when DisableFlagParsing is true and collects required-together, one-required, and mutually-exclusive annotations (lines 81-99). processFlagForGroupAnnotation considers a group only when all its flags are defined, using hasAllFlags (lines 111-134). validateRequiredFlagGroups permits all flags unset or all set; otherwise it sorts the missing names and returns an error requiring every group member to be set (lines 144-165).
