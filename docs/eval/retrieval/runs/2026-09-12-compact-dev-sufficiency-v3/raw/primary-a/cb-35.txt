The default `completion` command generates shell autocompletion scripts. `InitDefaultCompletionCmd` creates it unless default completion is disabled, there are no subcommands, or an existing command name/alias already matches (`completions.go:683–708`). It sets `NoArgs`, `NoFileCompletions`, visibility, and group ID. The Bash subcommand's help shows `source <(PROGRAM completion bash)` for loading completion in the current session and notes the `bash-completion` dependency (`completions.go:713–728`). `GenBashCompletion(w)` separately generates a script into a writer (`bash_completions.go:686–697`).
