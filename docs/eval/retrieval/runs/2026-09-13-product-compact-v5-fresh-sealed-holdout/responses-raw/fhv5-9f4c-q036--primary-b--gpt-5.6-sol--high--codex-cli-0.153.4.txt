`Help()` calls `c.HelpFunc()` with the command and an empty argument slice, then always returns `nil` (`command.go:470-476`).

`HelpFunc()` resolves behavior in this order (`command.go:450-468`):

1. Use `c.helpFunc` if set.
2. Otherwise recursively inherit `c.Parent().HelpFunc()` when there is a parent.
3. Otherwise use the default function, which:
   - calls `c.mergePersistentFlags()`,
   - renders `c.HelpTemplate()` to `c.OutOrStdout()`,
   - and, if `tmpl(...)` fails, reports the error with `c.PrintErrln(err)`.

Thus template errors are printed, not propagated by `Help()`, which still returns `nil`.
