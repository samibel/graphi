GenReSTCustom (doc/rest_docs.go, lines 55-130) builds a reStructuredText page for one cobra.Command by accumulating text in an in-memory buffer and flushing it to the caller's writer at the end. The signature is `func GenReSTCustom(cmd *cobra.Command, w io.Writer, linkHandler func(string, string) string) error`; the plain `GenReST(cmd, w)` shown just above it is a thin wrapper that calls `GenReSTCustom(cmd, w, defaultLinkHandler)`, so the custom version is identical except that link rendering is injected.

1. Initialization. The function first calls `cmd.InitDefaultHelpCmd()` and `cmd.InitDefaultHelpFlag()` to make sure the default help command and help flag exist on the command tree, then creates the accumulator `buf := new(bytes.Buffer)` and captures the full command path with `name := cmd.CommandPath()`. It then resolves the descriptive texts: `short := cmd.Short`, `long := cmd.Long`, and if `long` is empty it falls back to `short`. Finally it derives the RST reference anchor by replacing spaces with underscores: `ref := strings.ReplaceAll(name, " ", "_")`.

2. Header and Synopsis sections. It writes the anchor target `.. _<ref>:` followed by the command path as a section title underlined with `strings.Repeat("-", len(name))`, then the `short` text. After that it emits a `Synopsis` heading underlined with `~~~~~~~~` and the `long` text. If the command is runnable (`if cmd.Runnable()`), it appends a literal block `::\n\n  %s\n\n` containing `cmd.UseLine()` — the usage line. If the command has examples (`if len(cmd.Example) > 0`), it emits an `Examples` section (again underlined with `~~~~~~~~`) containing a literal block whose content is `indentString(cmd.Example, "  ")`, i.e. the example text indented by two spaces.

3. Options section. It delegates flag/option rendering to a helper: `if err := printOptionsReST(buf, cmd, name); err != nil { return err }` — an error here aborts the whole generation.

4. SEE ALSO section and links. Guarded by `if hasSeeAlso(cmd)`, it writes the `SEE ALSO` heading underlined with `~~~~~~~~`. Link formatting goes through the injected `linkHandler(name, ref)`:
   - Parent link: if `cmd.HasParent()`, it takes `parent := cmd.Parent()`, computes `pname := parent.CommandPath()` and `ref = strings.ReplaceAll(pname, " ", "_")`, and writes a bullet `* %s \t - %s\n` with `linkHandler(pname, ref)` and `parent.Short`. While there it also propagates the auto-gen-tag suppression downward: `cmd.VisitParents(func(c *cobra.Command) { if c.DisableAutoGenTag { cmd.DisableAutoGenTag = c.DisableAutoGenTag } })`.
   - Child links: it collects `children := cmd.Commands()`, sorts them alphabetically with `sort.Sort(byName(children))`, and iterates. Each child is skipped if `!child.IsAvailableCommand() || child.IsAdditionalHelpTopicCommand()`. For the remaining children it builds `cname := name + " " + child.Name()`, recomputes `ref = strings.ReplaceAll(cname, " ", "_")`, and writes a bullet `* %s \t - %s\n` with `linkHandler(cname, ref)` and `child.Short`. A trailing blank line closes the section.

5. Final output. Unless suppressed (`if !cmd.DisableAutoGenTag`), it appends the footer `*Auto generated by spf13/cobra on <date>*` with `time.Now().Format("2-Jan-2006")`. It then flushes the whole buffered page in one call, `_, err := buf.WriteTo(w)`, and returns that error — so the only writes to `w` happen at the very end, after the page has been fully assembled in memory.
