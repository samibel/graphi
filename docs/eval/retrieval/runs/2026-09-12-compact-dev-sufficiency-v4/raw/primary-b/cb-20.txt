Persistent flags propagate through a child's accumulated `parentsPflags` flag set. `updateParentsPflags` is documented to add new persistent flags from all parents and initialize that set if nil (`command.go:1855–1861`). `mergePersistentFlags` calls that updater, then adds the command's own `PersistentFlags()` and `parentsPflags` into `c.Flags()` (`command.go:1847–1853`). Lookup follows the same hierarchy: `persistentFlag(name)` first checks the command's own persistent flags, then refreshes and searches `parentsPflags` if no local match was found (`command.go:1805–1816`). `PersistentFlags()` itself represents flags specifically set on the current command (`command.go:1725–1729`).
