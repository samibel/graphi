`InitDefaultCompletionCmd` adds Cobra's default `completion` command, which generates an autocompletion script for a selected shell (`completions.go:678-715`). It does nothing when disabled, when the command has no subcommands, or when a command/alias named `completion` already exists. Its behavior is controlled by `CompletionOptions`, including whether the command is hidden and whether descriptions or the `--no-descriptions` flag are disabled (`completions.go:678-715`; constants at `completions.go:93-102`).
