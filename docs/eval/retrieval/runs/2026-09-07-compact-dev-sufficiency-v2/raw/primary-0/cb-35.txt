InitDefaultCompletionCmd in completions.go:683–710 creates a command for generating shell autocompletion scripts. It skips creation if DisableDefaultCmd is true, there are no subcommands, or a command already has the completion name or alias. The generated command accepts NoArgs, uses NoFileCompletions, takes visibility from HiddenDefaultCmd and a configured group ID, then is attached with AddCommand. The snippet also derives whether to offer a no-description flag from DisableNoDescFlag and DisableDescriptions.
