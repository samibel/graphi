`(*Command).RegisterFlagCompletionFunc(flagName, f)` registers a portable Go completion function for an existing flag. It returns an error if the flag does not exist or already has a function, and otherwise stores the function in the global flag-keyed map while holding `flagCompletionMutex` (`completions.go:35-36`, `completions.go:132-148`). The registered function can be retrieved with `GetFlagCompletionFunc`, which uses the read lock and returns `(func, exists)` (`completions.go:148-160`).
