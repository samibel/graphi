`(*Command).Find(args)` recursively searches downward from the highest command. At each node it strips flags, stays on the current command if no positional argument remains, otherwise passes the first non-flag token to `findNext`; on a match it removes that token and recurses into the child, and on no match it stops at the current command (`command.go:724-748`). Finally, commands without a custom `Args` validator are checked with `legacyArgs`; commands with one return directly (`command.go:742-748`).
