Based on the single provided source span, `doc/rest_docs.go` lines 55-130 (the full body of `GenReSTCustom`, plus the `GenReST` wrapper that delegates to it), GenReSTCustom builds a reStructuredText command page for a `*cobra.Command` in this order:

1. Initialization
- It first ensures defaults exist by calling `cmd.InitDefaultHelpCmd()` and `cmd.InitDefaultHelpFlag()`.
- It allocates an output accumulator with `buf := new(bytes.Buffer)` and derives page identity values: `name := cmd.CommandPath()`, `short := cmd.Short`, `long := cmd.Long` (falling back to `short` when `long` is empty: `if len(long) == 0 { long = short }`), and an RST anchor `ref := strings.ReplaceAll(name, " ", "_")`.

2. Header section
- Writes the RST target anchor `.. _<ref>:` followed by the command path as the page title, underlined with `strings.Repeat("-", len(name))`, then the `short` description line.

3. Synopsis section
- Writes the literal heading `Synopsis` underlined with `~~~~~~~~`, then the `long` text.

4. Usage line (conditional)
- If `cmd.Runnable()` is true, it appends an RST literal block via `fmt.Sprintf("::\n\n  %s\n\n", cmd.UseLine())`.

5. Examples section (conditional)
- If `len(cmd.Example) > 0`, it writes an `Examples` heading (`~~~~~~~~` underline) and a literal block of the example indented two spaces with `indentString(cmd.Example, "  ")`.

6. Options/flags section
- It delegates flag rendering to `printOptionsReST(buf, cmd, name)` and returns immediately if that call errors (`if err := printOptionsReST(buf, cmd, name); err != nil { return err }`).

7. SEE ALSO links section (conditional)
- Guarded by `hasSeeAlso(cmd)`, it writes the `SEE ALSO` heading (`~~~~~~~~` underline).
- Parent link: if `cmd.HasParent()`, it writes a bullet `* <link> - <parent.Short>` where the link text comes from the caller-supplied `linkHandler(pname, ref)` with `pname := parent.CommandPath()` and `ref` re-derived by replacing spaces with underscores. It also walks ancestors with `cmd.VisitParents` to propagate `DisableAutoGenTag` downward.
- Child links: it collects `children := cmd.Commands()`, sorts them with `sort.Sort(byName(children))`, and for each child that passes `child.IsAvailableCommand()` and is not `child.IsAdditionalHelpTopicCommand()`, writes a bullet `* <link> - <child.Short>` using `linkHandler(cname, ref)` where `cname := name + " " + child.Name()` and `ref` is again the underscore-joined form. It then writes a trailing blank line.

8. Final output
- Unless `cmd.DisableAutoGenTag` is set, it appends the footer `*Auto generated by spf13/cobra on <date>*` with the date formatted as `2-Jan-2006` via `time.Now().Format(...)`.
- Finally it flushes everything accumulated in the buffer to the caller's writer with `_, err := buf.WriteTo(w)` and returns that error.

So the whole page is assembled sequentially into a single `bytes.Buffer` (anchor -> title -> short -> Synopsis/long -> usage -> Examples -> options -> SEE ALSO links -> autogen tag) and emitted in one `WriteTo` at the end. Note also that the plain `GenReST(cmd, w)` entry point is exactly this same pipeline with the default link handler: `return GenReSTCustom(cmd, w, defaultLinkHandler)`.
