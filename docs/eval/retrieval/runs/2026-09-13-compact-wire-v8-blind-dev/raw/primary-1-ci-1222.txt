For a command flag, write a function with this signature:

```go
func(cmd *Command, args []string, toComplete string) ([]string, ShellCompDirective)
```

Then register it:

```go
err := cmd.RegisterFlagCompletionFunc("flag-name",
    func(cmd *Command, args []string, toComplete string) ([]string, ShellCompDirective) {
        return choices, directive
    },
)
```
