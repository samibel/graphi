`flag_groups.go` contains flag-group validation helpers. `ValidateFlagGroups` skips validation when flag parsing is disabled and collects required-together, one-required, and mutually-exclusive annotation groups (`flag_groups.go:81–99`). `processFlagForGroupAnnotation` ignores a group unless all its flags exist, using `hasAllFlags` (`flag_groups.go:121–134`, `111–119`). `validateRequiredFlagGroups` accepts all flags set or all unset, but returns a deterministically sorted missing-flags error for a partially set group (`flag_groups.go:144–165`).
