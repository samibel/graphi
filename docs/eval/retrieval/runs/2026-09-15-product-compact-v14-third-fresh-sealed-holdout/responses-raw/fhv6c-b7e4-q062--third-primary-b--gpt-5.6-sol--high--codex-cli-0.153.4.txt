For a Bash alias with Cobra completion, define the alias and register the original command’s generated completion function:

```bash
alias aliasname=origcommand
complete -o default -F __start_origcommand aliasname
```

This is documented in `site/content/completions/_index.md:402-408`.

Separately, Cobra command aliases are stored in `Command.Aliases`, described as substitutes for the first word in `Use` (`command.go:63`). `Command.HasAlias` checks them using `commandNameMatches` (`command.go:1505-1513`), respecting `EnableCaseInsensitive` (`command.go:1876-1885`).
