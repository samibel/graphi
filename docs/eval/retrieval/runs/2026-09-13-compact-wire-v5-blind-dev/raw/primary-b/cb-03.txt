`doc.GenMarkdownTree(cmd, dir)` recursively generates Markdown for a command and its descendants, using no file preamble and an identity link handler (`doc/md_docs.go:119-130`). `GenMarkdownTreeCustom` skips unavailable and additional-help-topic children, recursively processes eligible children, then writes the current command to `<dir>/<command_path_with_spaces_replaced_by_underscores>.md` via `GenMarkdownCustom` (`doc/md_docs.go:131-158`).
