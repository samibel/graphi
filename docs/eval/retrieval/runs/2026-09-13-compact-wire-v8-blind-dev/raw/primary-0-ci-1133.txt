Inside `Run`, `RunE`, or a pre-run hook, use the provided `cmd`:

```go
f := cmd.Flag("flag-name")
if f != nil {
    value := f.Value.String()
}
```

`Command.Flag(name)` first checks the command’s local flags with `c.Flags().Lookup(name)`, then searches inherited persistent flags via `c.persistentFlag(name)` ([command.go, lines 1794–1803](command.go#L1794), [command.go, lines 1805–1816](command.go#L1805)). The executing command is passed into handlers as `func(cmd *Command, args []string)` ([command.go, lines 124–134](command.go#L124)).
