Set the package-level `EnablePrefixMatching` variable to `true` before executing commands. Its declaration says to enable it this way (`cobra.go:54–55`), and `TestEnablePrefixMatching` does exactly that (`command_test.go:305–306`). It defaults to false (`cobra.go:46`). When enabled, matching collects commands for which `cmd.hasNameOrAliasPrefix(next)` is true (`command.go:774–775`), so the mechanism considers names and aliases.
