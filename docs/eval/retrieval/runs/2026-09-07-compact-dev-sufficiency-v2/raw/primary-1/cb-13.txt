`findSuggestions` returns no suggestions if `DisableSuggestions` is true and sets a nonpositive `SuggestionsMinimumDistance` to 2 before calling `SuggestionsFor` (`command.go:750–758`). `SuggestionsFor` iterates available child commands, computes `ld(typedName, cmd.Name(), true)`, and appends names whose distance is within that threshold or whose lowercased name starts with the lowercased input (`command.go:832–841`). It also checks `SuggestFor` entries with `strings.EqualFold`, although the match body is omitted (`command.go:842–843`).
