Use `MarkFlagDirname` on the flag:

```go
flagName := "output"
if err := cmd.MarkFlagDirname(flagName); err != nil {
    return err
}
```

Alternatively, register a completion function returning `ShellCompDirectiveFilterDirs`:

```go
cmd.RegisterFlagCompletionFunc("output",
    func(cmd *cobra.Command, args []string, toComplete string) ([]string, cobra.ShellCompDirective) {
        return nil, cobra.ShellCompDirectiveFilterDirs
    },
)
```
