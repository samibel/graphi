`MatchAll` runs positional validators in the same order they are passed, iterating left-to-right over `pargs` (`args.go:115–116`). It stops immediately when a validator returns a non-`nil` error and returns that error (`args.go:117–118`); otherwise, after all validators succeed, it returns `nil` (`args.go:121`). For example, `MatchAll(ExactArgs(n), OnlyValidArgs)` runs `ExactArgs` first, then `OnlyValidArgs` (`args.go:128–130`).
