To invoke a subcommand by default in Cobra, use the Execute() or ExecuteC() methods. The Execute() method (command.go:1038) uses os.Args[1:] by default and runs through the command tree to find the matching subcommand. ExecuteC() (command.go:1052) is the context-aware variant that performs the actual execution. For a default help subcommand specifically, call InitDefaultHelpCmd() (command.go:1229), which automatically adds a help command and is invoked when executing the command or calling help and usage. The Find() method (command.go:726) locates the target command in the hierarchy based on the provided arguments.
