`parent.AddCommand(children...)` rejects making a command its own child, assigns each child's `parent` field to the receiver, updates cached maximum use/path/name widths, propagates a global normalization function when configured, appends the child to `c.commands`, and marks the collection unsorted (`command.go:1302-1330`). `Parent` simply returns that pointer (`command.go:1842-1845`).
