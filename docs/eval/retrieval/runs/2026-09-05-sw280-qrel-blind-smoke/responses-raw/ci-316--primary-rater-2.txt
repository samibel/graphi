Yes. Each Command has its own pflag.FlagSet returned by Flags(), and that FlagSet has a SortFlags field you can set to false to disable alphabetical sorting of that command's flags in help/usage output.

Evidence: command_test.go:2135, function TestSortedFlags (ref_id eac8a74ffa239f98), whose snippet (evidence e162, command_test.go lines 2129-2141) reads:

// TestSortedFlags checks,
// if cmd.LocalFlags() is unsorted when cmd.Flags().SortFlags set to false.
// Related to https://github.com/spf13/cobra/issues/404.
func TestSortedFlags(t *testing.T) {
	c := &Command{}
	c.Flags().SortFlags = false
	names := []string{"C", "B", "A", "D"}
	for _, name := range names {
		c.Flags().Bool(name, false, "")
	}

This is a per-command setting (it's a field on the FlagSet obtained via that specific command's Flags() method, per the Flags() definition at command.go:1643, snippet e159), not a global switch — each command's flags can be independently set to unsorted this way.

Note this is distinct from EnableCommandSorting (cobra.go:59, snippet e161: "EnableCommandSorting controls sorting of the slice of commands, which is turned on by default. To disable sorting, set it to false."), which is a package-level variable controlling the order of *subcommands* returned by Command.Commands() (command.go:1293, snippet e158), not flags. For flags specifically, the mechanism is the FlagSet.SortFlags field shown above, set per command.
