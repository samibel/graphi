`(*Command).Execute()` executes the command tree using `os.Args[1:]` by default. It delegates to `c.ExecuteC()`, discards the returned command, and returns only the error (`command.go:1035–1041`).

`ExecuteC()` initializes a missing context with `context.Background()` and, if invoked on a child command, delegates execution to the root command (`command.go:1051–1062`). Run hooks execute in this order: `PersistentPreRun`, `PreRun`, `Run`, `PostRun`, `PersistentPostRun` (`command.go:114–123`).
