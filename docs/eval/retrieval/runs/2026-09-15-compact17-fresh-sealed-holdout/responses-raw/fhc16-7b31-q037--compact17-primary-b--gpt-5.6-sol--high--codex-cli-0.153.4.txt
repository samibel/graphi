`DebugFlags` performs a depth-first, pre-order traversal starting at its receiver:

- It defines a recursive `debugflags(*Command)` function and starts it with `debugflags(c)` (`command.go:1457–1490`).
- For each command `x`, it prints the command name if it has local or persistent flags (`command.go:1459–1461`).
- It visits `x.flags` first (`command.go:1462–1470`):
  - `[LP]` when the flag also resolves through `x.persistentFlag(f.Name)` and the command has persistent flags (`command.go:1464–1466`).
  - `[L]` otherwise (`command.go:1467–1468`).
- It then visits `x.pflags` (`command.go:1471–1481`), labeling entries `[P]`. When local flags exist, it prints a persistent flag only if `x.flags.Lookup(f.Name) == nil`, preventing an `[LP]` flag from being printed again (`command.go:1473–1477`).
- It prints `x.flagErrorBuf` (`command.go:1482`), then recursively processes each child in `x.commands` when `HasSubCommands()` is true (`command.go:1483–1487`).

Thus `[L]` means local-only, `[P]` persistent-only, and `[LP]` a flag present in the local/complete flag set that is also persistently owned or inherited.
