`RegisterFlagCompletionFunc` registers a shell-completion callback for a command flag:

```go
func (c *Command) RegisterFlagCompletionFunc(
    flagName string,
    f func(cmd *Command, args []string, toComplete string) ([]string, ShellCompDirective),

```

In `completions.go:132-146`, it:

- Finds the flag using `c.Flag(flagName)`.
- Returns an error if the flag does not exist.
- Locks `flagCompletionMutex`.

- Stores the callback in the global `flagCompletionFunctions` map and returns `nil`.
