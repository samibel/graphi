For one command page, `GenMarkdownCustom` processes these sections in order (`doc/md_docs.go:55–117`):

1. **Initialize:** Calls `cmd.InitDefaultHelpCmd()` and `cmd.InitDefaultHelpFlag()`, then builds output in a buffer.
2. **Title and description:** Writes `## ` plus `cmd.CommandPath()`, followed by `cmd.Short`.
3. **Synopsis and usage:** If `cmd.Long` is nonempty, writes `### Synopsis` and the long description. Independently, if `cmd.Runnable()`, writes `cmd.UseLine()` in a fenced code block.
4. **Examples:** If `cmd.Example` is nonempty, writes `### Examples` and a fenced example block.
5. **Options:** Calls `printOptions(buf, cmd, name)` and immediately returns any error. The response does not show that helper’s implementation.
6. **Related-command links:** If `hasSeeAlso(cmd)`:
   - Writes `### SEE ALSO`.
   - Adds the parent first, if present. Its label is `parent.CommandPath()`.
   - Gets children with `cmd.Commands()` and explicitly sorts them with `sort.Sort(byName(children))`.
   - Skips children satisfying `!child.IsAvailableCommand() || child.IsAdditionalHelpTopicCommand()`.
   - Each child’s label is `name + " " + child.Name()`.
   - For both parent and children, appends `markdownExtension` to the command path, replaces spaces with underscores using `strings.ReplaceAll`, and passes that destination through `linkHandler`. Each bullet includes the linked label and the command’s `Short` description.
7. **Footer and write:** Within the parent branch, `VisitParents` propagates any ancestor’s enabled `DisableAutoGenTag` to this command. Unless disabled, appends the autogenerated footer with `time.Now().Format("2-Jan-2006")`. Finally, calls `buf.WriteTo(w)` and returns its error.
