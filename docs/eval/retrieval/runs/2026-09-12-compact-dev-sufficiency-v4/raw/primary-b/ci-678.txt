Pass the desired flag arguments with `cmd.SetArgs([]string{"--a=foo"})` before running the command in the test. `SetArgs(a []string)` directly sets `c.args`, overriding the usual `os.Args[1:]`, and its comment specifically calls this useful for testing (`command.go:274–278`). A supplied flag-group test uses `[]string{"--a=foo"}` as its argument input (`flag_groups_test.go:65–66`). Use a flag name defined by your command.
