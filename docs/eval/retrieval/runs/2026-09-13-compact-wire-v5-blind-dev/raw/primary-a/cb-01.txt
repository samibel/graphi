`(*Command).ExecuteC` ensures the command has a context (defaulting to `context.Background`), redirects execution to the root when called on a child, runs the Windows pre-exec hook, initializes the default help and completion commands, validates command groups, and chooses explicit `c.args` or normally `os.Args[1:]` (`command.go:1051-1082`). `Execute` is the error-only wrapper around it (`command.go:1035-1041`), while `ExecuteContextC` first installs the supplied context (`command.go:1042-1050`).
