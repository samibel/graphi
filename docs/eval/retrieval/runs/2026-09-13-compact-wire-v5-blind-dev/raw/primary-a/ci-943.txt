`--version` is only created automatically when the command's `Version` field is non-empty and the command has not already defined a `version` flag (`command.go:108-109`, `command.go:1202-1203`). Set `cmd.Version` before execution; Cobra then adds its boolean version flag and marks it as Cobra-created (`command.go:1221-1225`). If needed, customize the rendered output with `SetVersionTemplate` (`command.go:352-355`); otherwise the inherited/default template prints the command name and version (`command.go:598-609`).
