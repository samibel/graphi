Cobra’s `Find` method recursively walks down the command tree:

1. It removes flags from the current arguments with `stripFlags(innerArgs, c)`.
2. If no non-flag arguments remain, it returns the current command.
3. Otherwise, it treats the first non-flag argument as the possible subcommand name and calls `c.findNext(nextSubCmd)`.
4. When a match is found, it removes that argument using `c.argsMinusFirstX(...)` and repeats the process on the matched subcommand.
5. If no match exists, it stops and returns the current command with the remaining arguments.

Evidence: `command.go:724-748`, especially `stripFlags`, `findNext`, `argsMinusFirstX`, and the recursive `innerfind` call.

`findNext` checks each child command for:

- An exact name match via `commandNameMatches(cmd.Name(), next)`.
- An alias match via `cmd.HasAlias(next)`.
- If `EnablePrefixMatching` is enabled, a name or alias prefix match. A prefix is accepted only when exactly one child matches.

For an exact name or alias match, it also records the supplied spelling in `cmd.commandCalledAs.name`. Evidence: `command.go:767-786`.
