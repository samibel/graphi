`(*Command).Find` recursively searches downward from the highest node. At each command it strips flags, takes the first remaining token as the prospective subcommand, calls `findNext`, removes that token from the original argument list, and recurses into the match; if no match remains, it returns the current command and remaining arguments (`command.go:724-748`). If the selected command has no custom `Args` validator, it additionally applies `legacyArgs` to the remaining non-flag arguments (`command.go:744-748`).
