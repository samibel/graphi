Inside a run hook, use the `cmd *Command` passed to that hook and call `cmd.Flag("name")`. `Flag` first searches the command's applicable flag set and then searches persistent flags up the command tree, returning the matching `*pflag.Flag` (`command.go:1795-1807`). If you need the command selected by top-level execution outside the hook, `ExecuteC` returns a `*Command` along with the error (`command.go:1051-1056`).
