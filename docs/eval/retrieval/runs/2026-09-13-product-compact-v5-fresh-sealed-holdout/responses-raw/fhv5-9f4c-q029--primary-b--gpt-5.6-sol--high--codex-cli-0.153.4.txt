A typed prefix is accepted only when it uniquely matches exactly one subcommand by the start of its name or an alias. In `command.go:767–786`, prefix matches are collected and returned only when `len(matches) == 1`; `hasNameOrAliasPrefix` checks `strings.HasPrefix` against the command name and each alias (`command.go:1524–1538`). Exact name or alias matches are accepted immediately.
