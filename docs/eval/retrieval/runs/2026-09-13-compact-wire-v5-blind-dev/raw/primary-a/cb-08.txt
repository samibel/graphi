`doc/man_docs.go` contains man-page generation and header setup. `GenMan` accepts an optional header, fills defaults from the command path, generates the page, renders it through `md2man`, and writes it to the supplied writer (`doc/man_docs.go:103-116`). `fillHeader` defaults the title, section, date, and generated-source text; it honors `SOURCE_DATE_EPOCH` for reproducible dates and errors if that value is invalid (`doc/man_docs.go:118-141`). Tree generation is configured through `GenManTreeOptions` (`doc/man_docs.go:82-88`).
