Cobra automatically completes commands and flags, while noun and flag-value completion can be customized; static noun choices use `ValidArgs` (`site/content/completions/_index.md:117-127`).

`(*Command).InitDefaultCompletionCmd` adds the default `completion` command unless it is disabled, the command has no subcommands, or a program-defined `completion` command already exists (`completions.go:678-685`). Descriptions can be disabled with `rootCmd.CompletionOptions.DisableDescriptions = true` (`site/content/completions/_index.md:112-115`) or via the `no-descriptions` flag (`completions.go:95-102`).
