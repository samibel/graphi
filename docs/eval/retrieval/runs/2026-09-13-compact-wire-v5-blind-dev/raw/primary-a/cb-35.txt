On execution, `InitDefaultCompletionCmd` adds a `completion` command that generates shell scripts, unless default completion is disabled, the command has no subcommands, or a command/alias named `completion` already exists (`completions.go:678-696`). The generated command accepts no positional arguments, disables file completion, can be hidden or assigned a group ID, and respects options for disabling descriptions and the `--no-descriptions` flag (`completions.go:697-715`, `completions.go:93-104`). Individual generators, such as `GenBashCompletion`, write the actual script (`bash_completions.go:685-687`).
