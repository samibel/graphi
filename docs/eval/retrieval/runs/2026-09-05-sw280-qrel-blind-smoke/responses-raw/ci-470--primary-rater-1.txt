To call the help command on demand, use the Help() method on a Command object (command.go:473), which "puts out the help for the command" by calling c.HelpFunc()(c, []string{}) per the snippet (e62). Alternatively, invoke the help command through the CLI: Cobra automatically adds a help command when you have subcommands, called via 'app help' or 'app help <command>' (site/content/user_guide.md:492, e65). For custom implementations, define your own help command using SetHelpCommand(cmd *Command) as documented in site/content/user_guide.md:541-547 (e64). The default help command is initialized automatically via InitDefaultHelpCmd() (command.go:1229, e63), which "is called automatically by executing the c or by calling help and usage."
