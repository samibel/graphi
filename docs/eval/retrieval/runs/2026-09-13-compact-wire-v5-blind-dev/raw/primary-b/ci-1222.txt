For a flag, call `cmd.RegisterFlagCompletionFunc("flag-name", func(cmd *cobra.Command, args []string, toComplete string) ([]string, cobra.ShellCompDirective) { ... })`; return candidate strings plus an appropriate directive. The exact callback shape and registration API are shown at `completions.go:133-134`. Cobra stores these callbacks by flag (`completions.go:36`). For positional arguments, use `ValidArgsFunction`; both mechanisms are portable across Bash, Zsh, Fish, and PowerShell (`site/content/completions/_index.md:477-478`).
