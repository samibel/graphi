Use the `*Command` passed to the currently executing Run hook and call `cmd.Flag("name")`; `Flag` looks in the command's effective flag set (`command.go:1795-1797`). If you need the selected command outside the hook, use `ExecuteC`/`ExecuteContextC`, whose signatures return `*Command` along with the error (`command.go:1045-1056`). Plain `Execute` discards that command and returns only the error (`command.go:1035-1042`).
