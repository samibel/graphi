`shell_completions.go` provides helpers for flag completion and required flags. `(*Command).MarkFlagFilename(name, extensions...)` restricts completions to the specified file extensions by delegating with `c.Flags()` (`shell_completions.go:42–46`). `MarkPersistentFlagFilename` does the same with `c.PersistentFlags()` (`shell_completions.go:58–63`). `MarkFlagRequired(flags *pflag.FlagSet, name string) error` prioritizes a flag during completion and causes an error when the command is invoked without it (`shell_completions.go:35–38`).
