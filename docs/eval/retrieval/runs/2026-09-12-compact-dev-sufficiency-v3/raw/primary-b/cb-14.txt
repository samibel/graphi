Shell scripts request completion through the hidden command described by ShellCompRequestCmd; ShellCompNoDescRequestCmd is the variant without descriptions (completions.go:27-31). The command's Run handler dispatches directly to cmd.getCompletions(args), which returns the final command, completions, directive, and error. Errors are reported with CompErrorln but processing continues so valid results and the directive can still be emitted. CalledAs() identifies the no-description variant (completions.go:202-217).
