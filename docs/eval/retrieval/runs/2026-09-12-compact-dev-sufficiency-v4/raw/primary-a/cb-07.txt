`flag_groups.go` contains command flag-group validation. `ValidateFlagGroups` skips checks when `DisableFlagParsing` is true and otherwise visits flags to build status maps for `requiredAsGroup`, `oneRequired`, and `mutuallyExclusive` annotations (`flag_groups.go:81–99`). `processFlagForGroupAnnotation` only considers groups whose flags are all defined, using `hasAllFlags` to check lookups (`flag_groups.go:111–134`). `validateRequiredFlagGroups` accepts groups with none or all flags set; for a partial group it sorts missing names and returns an error requiring every member (`flag_groups.go:144–165`).
