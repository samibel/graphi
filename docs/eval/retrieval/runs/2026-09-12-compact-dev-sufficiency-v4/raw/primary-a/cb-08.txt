`doc/man_docs.go` provides man-page generation: `GenMan(cmd *cobra.Command, header *GenManHeader, w io.Writer) error` writes a command's man page, accepts a nil header, and requires a writer (`doc/man_docs.go:103–106`). `fillHeader` supplies an uppercase title with spaces replaced by escaped hyphens, defaults the section to `1`, and uses the current time or parsed `SOURCE_DATE_EPOCH` when no date is supplied; invalid epoch values return an error. It formats the date as `Jan 2006` and adds `Auto generated by spf13/cobra` when the source is empty and auto-generation is enabled (`doc/man_docs.go:118–141`). `GenManTreeOptions` includes header and output-path fields (`doc/man_docs.go:82–86`).
