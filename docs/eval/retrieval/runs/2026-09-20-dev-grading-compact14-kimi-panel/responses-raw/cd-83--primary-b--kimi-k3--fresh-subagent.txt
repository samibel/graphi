GenReSTCustom (doc/rest_docs.go, lines 61-130) builds a reStructuredText page for a *cobra.Command by writing sequentially into a bytes.Buffer and finally flushing it to the caller's io.Writer. The pipeline, in order:

1. Initialization (lines 63-73)
   - Calls cmd.InitDefaultHelpCmd() and cmd.InitDefaultHelpFlag() so help command/flag exist before documenting.
   - Creates buf := new(bytes.Buffer) and captures name := cmd.CommandPath().
   - Takes short := cmd.Short and long := cmd.Long; if long is empty it falls back to short ("if len(long) == 0 { long = short }").
   - Computes the reST anchor ref := strings.ReplaceAll(name, " ", "_").

2. Header / title section
   - Writes the anchor ".. _" + ref + ":\n\n".
   - Writes the command name followed by an underline of dashes matching its length: strings.Repeat("-", len(name)).
   - Writes short, then a "Synopsis" section header with "~~~~~~~~" underline, then "\n" + long + "\n\n".

3. Usage line
   - If cmd.Runnable(), writes a literal block: fmt.Sprintf("::\n\n  %s\n\n", cmd.UseLine()).

4. Examples section
   - If len(cmd.Example) > 0, writes an "Examples" / "~~~~~~~~" header and the example text indented by two spaces via fmt.Sprintf("::\n\n%s\n\n", indentString(cmd.Example, "  ")).

5. Options section
   - Delegates to printOptionsReST(buf, cmd, name); if that returns an error, GenReSTCustom returns the error immediately.

6. SEE ALSO / links section (guarded by hasSeeAlso(cmd))
   - Writes "SEE ALSO" / "~~~~~~~~" header.
   - Parent link: if cmd.HasParent(), takes parent := cmd.Parent(), pname := parent.CommandPath(), recomputes ref = strings.ReplaceAll(pname, " ", "_"), and writes fmt.Sprintf("* %s \t - %s\n", linkHandler(pname, ref), parent.Short) — i.e. the caller-supplied linkHandler produces the link text from name and ref. It then runs cmd.VisitParents to propagate DisableAutoGenTag down from any parent that sets it.
   - Child links: children := cmd.Commands(), sorted with sort.Sort(byName(children)); for each child, skipping ones that fail child.IsAvailableCommand() or pass child.IsAdditionalHelpTopicCommand(), it builds cname := name + " " + child.Name(), ref := strings.ReplaceAll(cname, " ", "_"), and writes fmt.Sprintf("* %s \t - %s\n", linkHandler(cname, ref), child.Short). (child.Name() comes from Command.Name() in command.go:1495-1503, the first word of the Use line.) A trailing "\n" closes the list.

7. Final output
   - Unless cmd.DisableAutoGenTag is set, appends "*Auto generated by spf13/cobra on " + time.Now().Format("2-Jan-2006") + "*\n".
   - Flushes with _, err := buf.WriteTo(w) and returns err.
