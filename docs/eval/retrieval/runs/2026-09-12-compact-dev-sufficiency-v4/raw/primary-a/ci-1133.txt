On the current command object, call `cmd.Flag("flag-name")` to obtain the matching flag; the method is documented to climb the command tree and begins with `c.Flags().Lookup(name)` (`command.go:1794–1797`). To look directly in the current command's flag set, use `cmd.Flags().Lookup("flag-name")`. Persistent lookup checks the command's own persistent flags, then refreshes and searches parent persistent flags (`command.go:1805–1816`). The execution code invokes `cmd.execute(flags)` on the selected command (`command.go:1114–1115`), and `ExecuteC()` exposes a returned `*Command` (`command.go:1051–1053`).
