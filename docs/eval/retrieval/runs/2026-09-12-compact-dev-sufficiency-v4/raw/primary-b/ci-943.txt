Check that the command's `Version` is nonempty, for example `cmd.Version = "1.0.0"`. `InitDefaultVersionFlag` returns immediately when `c.Version == ""` (`command.go:1202–1207`), and the `Version` field comment says a nonempty value enables addition of the boolean version flag when one has not already been defined (`command.go:108–109`). An existing version flag also prevents default creation (`command.go:1202`). Setting a version template alone sets `c.versionTemplate`, not `c.Version` (`command.go:352–355`). The bundle does not show your command configuration, so these are the supported conditions to check rather than a confirmed diagnosis of your instance.
