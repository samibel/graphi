Use the subcommand's cmd.Flag("name") or cmd.Flags().Lookup("name") for a global flag defined persistently on an ancestor. Flags is documented as the complete flag set including persistent flags declared by all parents (command.go:1641-1643), and Flag begins by looking up the name in that set (command.go:1795-1796). Local nonpersistent flags explicitly do not persist to subcommands (command.go:1655-1656).
