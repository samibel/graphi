Cobra identifies required flags for completion via a flag annotation: flags marked required carry the annotation key `BashCompOneRequiredFlag` (the string "cobra_annotation_bash_completion_one_required_flag", defined in the constants block in bash_completions.go, lines 28-34). Marking happens in `MarkFlagRequired` (shell_completions.go, lines 35-40), which calls `flags.SetAnnotation(name, BashCompOneRequiredFlag, []string{"true"})`; the `Command` methods `MarkFlagRequired` (shell_completions.go, 21-26) and `MarkPersistentFlagRequired` (28-33) just apply that to the command's local or persistent FlagSet.

At completion time, `completeRequireFlags` in completions.go (lines 567-590) walks every flag of the final command and checks for that annotation: for each `*pflag.Flag`, `if _, present := flag.Annotations[BashCompOneRequiredFlag]; present` and `!flag.Changed` — i.e., the flag is annotated required but has not already been set on the command line — then it offers the flag name as a completion via `getFlagNameCompletions(flag, toComplete)`.

The scan covers both inherited and local flags by calling `finalCmd.InheritedFlags().VisitAll(...)` and `finalCmd.NonInheritedFlags().VisitAll(...)`. The code comments explain it deliberately does NOT use `finalCmd.Flags()` because `ParsedFlags()` may not have been called for commands with `DisableFlagParsing`, and it is `ParseFlags()` that merges inherited and non-inherited flags.
