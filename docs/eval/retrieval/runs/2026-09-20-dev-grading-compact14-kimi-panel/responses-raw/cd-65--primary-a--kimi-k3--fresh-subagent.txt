    // AllChildCommandsHaveGroup returns if all subcommands are assigned to a group
    func (c *Command) AllChildCommandsHaveGroup() bool {
        for _, sub := range c.commands {
            if (sub.IsAvailableCommand() || sub == c.helpCommand) && sub.GroupID == "" {
                return false
            }
        }
        return true
    }

Behavior: it iterates over the command's registered subcommands (c.commands). For each subcommand that is either an available command (sub.IsAvailableCommand()) or the command's help command (sub == c.helpCommand), it checks the subcommand's GroupID. If any such subcommand has an empty GroupID (sub.GroupID == ""), the method returns false immediately; otherwise, after the loop completes, it returns true. In other words, it reports true exactly when every available subcommand (plus the help command) has been assigned a non-empty group ID.
