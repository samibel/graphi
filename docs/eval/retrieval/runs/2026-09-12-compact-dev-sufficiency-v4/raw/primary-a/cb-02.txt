`(*Command).MarkFlagsMutuallyExclusive(flagNames ...string)` annotates a group so invoking the command with more than one member produces an error (`flag_groups.go:63–78`). It merges persistent flags, looks up each name, panics if a flag is missing, and appends the space-joined group to that flag's `mutuallyExclusive` annotations, panicking on annotation errors. Appending permits membership in multiple groups. `ValidateFlagGroups` handles group validation and returns immediately when `DisableFlagParsing` is true (`flag_groups.go:80–90`).
