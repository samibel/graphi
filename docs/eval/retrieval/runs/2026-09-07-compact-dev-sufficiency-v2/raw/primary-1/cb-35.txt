The default completion command is initialized by `(*Command).InitDefaultCompletionCmd` in `completions.go:683–710`. It generates autocompletion scripts for a selected shell, and creation is skipped if disabled, if there are no subcommands, or if a command already has the completion name or alias. The constructed command uses `NoArgs`, `NoFileCompletions`, the configured hidden status and group ID, and is added with `c.AddCommand(completionCmd)`.
