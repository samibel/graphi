The man-page generator performs a depth-first, children-before-parent walk. `GenManTreeFromOpts` iterates `cmd.Commands()`, skips unavailable commands and additional help topics, recursively generates each remaining child, then creates the current command's output file and calls `GenMan` (`doc/man_docs.go:46-80`). Filenames use the command path with spaces replaced by the configured separator (default `_`) and the header section (default `1`) as the extension (`doc/man_docs.go:60-80`).
