Shell completion includes a default command initialized by `(*Command).InitDefaultCompletionCmd()`. Initialization returns when `CompletionOptions.DisableDefaultCmd` is true or there are no subcommands; the comment also lists an existing program-provided `completion` command as a reason not to create one (`completions.go:681–685`). Disable descriptions with `rootCmd.CompletionOptions.DisableDescriptions = true` (`site/content/completions/_index.md:111–114`). Completion code must avoid debug prints to stdout because scripts interpret them as completion choices; the documentation points to Cobra debugging helpers such as `cobra.CompErrorln` (`site/content/completions/_index.md:268–270`).
