Shell scripts dispatch completion requests through a hidden command:

- `ShellCompRequestCmd` is defined as `__complete`; `ShellCompNoDescRequestCmd` is `__completeNoDesc` for results without descriptions (`completions.go:26-33`).
- Bash, Zsh, Fish, and PowerShell generators select `ShellCompRequestCmd` via `compCmd` (`bash_completionsV2.go:32`, `zsh_completions.go:88`, `fish_completions.go:31`, `powershell_completions.go:34-35`).
- The hidden command’s `Run` handler passes its arguments to `cmd.getCompletions(args)`, which returns the resolved command, completion candidates, directive, and error (`completions.go:205-215`).
- The handler detects the no-description variant with `cmd.CalledAs() == ShellCompNoDescRequestCmd` before emitting the returned candidates (`completions.go:205-215`).
