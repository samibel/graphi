Define the global flag as a persistent flag on the parent/root command, then access it from the subcommand with:

```go
f := subCommand.Flag("flag-name")
```

`Command.Flag` “climbs up the command tree” and, if the flag is not local, calls `persistentFlag` ([command.go:1794–1803]). That method checks the command’s persistent flags and inherited parent flags via `parentsPflags.Lookup(name)` ([command.go:1805–1816]). Thus, only persistent parent flags are inherited; local non-persistent flags do not persist to subcommands ([command.go:1655–1666]).
