The default `completion` command generates an autocompletion script for a selected shell (`completions.go:678–715`; name constant at line 98). `InitDefaultCompletionCmd` skips creation if disabled, if the command has no subcommands, or if a child already has the completion name or alias. Otherwise it constructs and adds a command with `Args: NoArgs`, `ValidArgsFunction: NoFileCompletions`, and configured hidden/group settings, then begins creating a `bash` subcommand. Description options govern the `no-descriptions` flag and generated descriptions (`completions.go:695–715`, `99`). Bash generation APIs shown include `GenBashCompletion(w io.Writer)` and `GenBashCompletionFileV2(filename string, includeDesc bool)` (`bash_completions.go:685–687`, `bash_completionsV2.go:381–383`).
