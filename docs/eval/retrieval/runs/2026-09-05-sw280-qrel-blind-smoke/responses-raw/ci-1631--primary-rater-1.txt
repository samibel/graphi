Yes, it is possible to remove error log output. The cobra.Command type provides SetOutput (command.go:283) which sets the destination for usage and error messages, with the note that SetOut and/or SetErr should be used instead. Additionally, ErrOrStderr (command.go:385) returns output to stderr through getErr, and PrintErr (command.go:1411) is a convenience method that prints to the defined Err output. The SetOutput method accepts an io.Writer parameter that can be configured to discard error output, and the documentation at command.go:277-289 states "If output is nil, os.Stderr is used," indicating that error destinations are configurable rather than fixed to stderr.
