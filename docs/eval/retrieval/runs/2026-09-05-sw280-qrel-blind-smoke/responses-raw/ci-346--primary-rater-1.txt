To add a required argument in Cobra, set the `Args` field of the `Command` struct to use a built-in validator. Specifically, use `cobra.MinimumNArgs(n)` to require at least n arguments. The `Args` field is a `PositionalArgs` function that validates positional arguments (site/content/user_guide.md:367), and the `ValidateArgs` method (command.go:1139) executes this validator when the command runs. For example, `MinimumNArgs(1)` (args.go:74) returns an error if fewer than 1 argument is provided, enforcing the requirement.
