To test whether a command has inherited flags, call `cmd.HasInheritedFlags()`; it returns `c.InheritedFlags().HasFlags()` (`command.go:1767–1769`). For a specific flag, check `cmd.InheritedFlags().Lookup("flag-name") != nil`: the inherited set is populated from parent flags only when the name is absent from both that set and local flags (`command.go:1696–1714`). Use `HasAvailableInheritedFlags()` when you want to exclude hidden or deprecated flags (`1788–1792`).
