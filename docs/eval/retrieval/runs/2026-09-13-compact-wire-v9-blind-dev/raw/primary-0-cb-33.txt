Cobra supports POSIX-compliant flags and Go’s `flag` package. Commands can define:

- Persistent flags inherited by child commands (`README.md:68-74`).
- Local flags available only to the current command (`README.md:72-74`).
- `Command.Flags()`, returning all applicable local and persistent flags from the command and its parents (`command.go:1641-1653`).
- `Command.LocalFlags()`, including current-command flags while handling inherited flags and shadowing (`command.go:1668-1693`).
- `Command.LocalNonPersistentFlags()`, filtering out persistent flags so only non-inherited command-specific flags remain (`command.go:1655-1666`).
