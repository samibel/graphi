`GenMarkdownTree(cmd, dir)` generates Markdown files for a Cobra command and all available descendants in `dir` (`doc/md_docs.go:119-129`). It delegates to:

```go
GenMarkdownTreeCustom(cmd, dir, emptyStr, identity)
```

Thus, it adds no file preamble and leaves links unchanged.

`GenMarkdownTreeCustom` recursively skips unavailable commands and additional help topics, names each file from `cmd.CommandPath()` with spaces replaced by underscores plus `.md`, creates it under `dir`, writes the optional preamble, then calls `GenMarkdownCustom` (`doc/md_docs.go:131-158`; extension defined at `doc/md_docs.go:30`).

The comments warn that command names containing `-` can cause filename collisions or undefined output (`doc/md_docs.go:119-125`).
