Define the flags first, then pass their names to the command:

```go
cmd.MarkFlagsMutuallyExclusive("flag-a", "flag-b")
```

`flag_groups.go:62-77` defines `(*Command).MarkFlagsMutuallyExclusive(flagNames ...string)` and states that Cobra errors when more than one flag in the set is used. Each name must already exist: the method calls `c.Flags().Lookup(v)` and panics if it returns `nil` (`flag_groups.go:67-71`). Persistent and inherited flags are included through `c.mergePersistentFlags()` (`flag_groups.go:65`; `command.go:1847-1853`).
