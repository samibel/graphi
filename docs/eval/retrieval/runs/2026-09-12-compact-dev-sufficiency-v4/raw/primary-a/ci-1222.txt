For a flag, write a Go callback with signature `func(cmd *Command, args []string, toComplete string) ([]string, ShellCompDirective)` and pass it to `cmd.RegisterFlagCompletionFunc("flag-name", callback)`, checking its returned error. This exact registration API is shown at `completions.go:133–134`; the callback map at `completions.go:36–37` confirms the same function type. The callback receives the command, argument slice, and text to complete, and returns completion strings plus a shell directive. The response does not provide directive meanings or a command-argument callback registration API.
