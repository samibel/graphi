When a command’s `inReader` is nil, `getIn(def)` recursively calls `c.parent.getIn(def)`, so it inherits the nearest ancestor’s non-nil input reader. If no ancestor has one, it returns the supplied default `def` (`command.go`, lines 414–422).

`SetIn` assigns `c.inReader` directly (`command.go`, lines 300–304); `HasParent` checks whether `c.parent != nil` (lines 1631–1634).
