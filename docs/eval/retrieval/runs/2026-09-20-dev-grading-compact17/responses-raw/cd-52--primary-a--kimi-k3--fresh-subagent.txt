Use `MatchAll(pargs ...PositionalArgs)`. Pass it the validators you want to combine, and assign the result to the `Args` field of your `Command`.

Evidence and mechanics:

1. The user guide (site/content/user_guide.md, lines 384-397 and the follow-up read of lines 367-421) states: "Moreover, `MatchAll(pargs ...PositionalArgs)` enables combining existing checks with arbitrary other checks," and gives this example:

```go
var cmd = &cobra.Command{
  Short: "hello",
  Args: cobra.MatchAll(cobra.ExactArgs(2), cobra.OnlyValidArgs),
  Run: func(cmd *cobra.Command, args []string) {
    fmt.Println("Hello, World!")
  },
}
```

2. The implementation (args.go, lines 112-122) shows how the combination behaves: each validator is run in order and the first error short-circuits:

```go
func MatchAll(pargs ...PositionalArgs) PositionalArgs {
	return func(cmd *Command, args []string) error {
		for _, parg := range pargs {
			if err := parg(cmd, args); err != nil {
				return err
			}
		}
		return nil
	}
}
```

So `MatchAll` returns a single `PositionalArgs` validator that fails if any of the combined validators fails.

3. What you can pass: any value of type `PositionalArgs`, defined in args.go lines 21-22 as `type PositionalArgs func(cmd *Command, args []string) error`. The guide's list of built-ins includes `NoArgs`, `ArbitraryArgs`, `MinimumNArgs(int)`, `MaximumNArgs(int)`, `ExactArgs(int)`, `RangeArgs(min, max)`, and `OnlyValidArgs`. You can also pass your own custom function of that signature (the guide shows a custom `Args` function; nothing in `MatchAll` restricts its arguments to built-ins).

4. Deprecation note (args.go, lines 124-131): `ExactValidArgs(n)` is deprecated — its body is literally `return MatchAll(ExactArgs(n), OnlyValidArgs)` — so the documented replacement is `MatchAll(ExactArgs(n), OnlyValidArgs)`.

5. Alternative composition style: instead of `MatchAll`, you can write a single custom validator and invoke built-ins inside it, as the follow-up read (user_guide.md, lines ~399-421) demonstrates with `cobra.MinimumNArgs(1)(cmd, args)` followed by custom logic. But for simply combining several validators, `MatchAll` is the intended mechanism.
