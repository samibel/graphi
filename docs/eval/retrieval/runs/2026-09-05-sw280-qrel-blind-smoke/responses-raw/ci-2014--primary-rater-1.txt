To call a command from another command with flags, use the ExecuteC() method on the Command type (command.go:1052), which executes the command. The command tree traversal is handled by the Traverse() method (command.go:790), which is designed to "traverse the command tree to find the command, and parse args for each parent" (command.go:784-796, e128). The Flags() method (command.go:1643) returns the complete FlagSet that applies to a command, including flags declared locally and by all parent commands. Additionally, the Find() method (command.go:726) can be used to locate the target command given args and the command tree structure.
