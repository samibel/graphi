Completion options in this repository (Cobra) are controlled by the `CompletionOptions` struct, defined in `completions.go` (lines 103-116). It has four boolean fields:

- `DisableDefaultCmd` — prevents Cobra from creating a default 'completion' command
- `DisableNoDescFlag` — prevents Cobra from creating the '--no-descriptions' flag for shells that support completion descriptions
- `DisableDescriptions` — turns off all completion descriptions for shells that support them
- `HiddenDefaultCmd` — makes the default 'completion' command hidden

Per the docs (`site/content/completions/_index.md`, lines 94-95), these options configure the default `completion` command, and "to configure such options you must set the `CompletionOptions` field on the *root* command."
