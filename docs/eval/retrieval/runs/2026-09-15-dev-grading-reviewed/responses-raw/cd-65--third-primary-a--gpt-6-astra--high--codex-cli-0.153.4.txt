`(*Command).AllChildCommandsHaveGroup() bool` checks whether every available immediate child command, plus the designated help command, has a nonempty `GroupID`.

In `command.go:1337–1343`, it loops over `c.commands` and returns `false` when:
```go
(sub.IsAvailableCommand() || sub == c.helpCommand) && sub.GroupID == ""
```
Otherwise, it returns `true`, including when there are no children.

`IsAvailableCommand` excludes deprecated, hidden, and designated help commands, and requires the command to be runnable or have available subcommands (`command.go:1560–1576`). The explicit help-command check includes that command anyway.

The method does not recursively check descendants or verify that a nonempty `GroupID` names an existing group; group existence is checked separately by `ContainsGroup` (`command.go:1346–1354`).
