Yes—override the default flags before execution: `InitDefaultHelpFlag` only adds `BoolP("help", "h", ...)` when no `"help"` flag exists ([command.go:1183–1198]), and initialization is deliberately delayed “to allow for user overriding” ([command.go:883–886]). Define `help` without the `h` shorthand and register `h` separately with your own handling. By default, both forms set the same `"help"` boolean, which is read at [command.go:894–905], so they cannot otherwise be distinguished.
